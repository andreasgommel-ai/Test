# Mercer AI Impact — Careers in Europe (Executive Deck)

A Mercer-branded, 12-slide executive briefing on AI's impact on the European
workforce, and how Mercer's Career consulting services are responding.

## Files
- `Mercer_AI_Impact_Careers_Europe.pptx` — the generated deck (16:9, editable).
- `build_deck.py` — generator script (run `python build_deck.py`).
- `mercer_brand.py` — reusable Mercer-branded slide engine (palette, layouts).
- `RESEARCH_NOTES.md` — verified figures and full source list.

## Rebuild
```bash
pip install python-pptx
python build_deck.py
```

## Brand note
Mercer's parent, Marsh McLennan, is rebranding all businesses to "Marsh"
(effective Jan 2026). This deck uses Mercer's established identity (deep
"Mercer blue" anchored on the Marsh McLennan family palette). Fonts use
Georgia (headlines) / Calibri (body) as broadly available substitutes; swap
for Mercer's licensed brand fonts if available.

## Sourcing
All statistics are cited on-slide and detailed in `RESEARCH_NOTES.md`
(IMF, WEF, McKinsey, PwC, OECD, Cedefop, Eurostat, EU Commission, EY,
Mercer Global Talent Trends 2024 & 2026). Several primary PDFs were
corroborated via primary-document extracts; confirm exact wording against
source PDFs before external publication.
